❓ CARA MAIN

🏁 Balap Drag 402m

Lampu menyala 3-2-1 lalu GO!. Tekan GAS tepat saat GO — reaksi cepat = start cepat. Gas sebelum GO = FALSE START dan langsung kalah.

⚙ Pindah Gigi

Perhatikan jarum RPM. Pindah gigi saat jarum di zona hijau (power band) supaya akselerasi maksimal. Terlalu cepat = ngempos, terlalu lambat = mentok limiter.

💨 Nitro

Tekan NITRO untuk boost. Jumlahnya terbatas — pakai di saat yang tepat, biasanya di gigi 3-4 atau menjelang finis.

🔧 Garasi

Menang balapan dapat koin. Pakai koin untuk upgrade Mesin, Knalpot, Ban, dan Nitro (masing-masing 5 level).

👥 Mabar

Lokal: 2 pemain di satu HP/laptop, layar split. Online: buat/gabung room pakai kode, balapan bareng lewat server.

📷 Kamera 3D

Kamera mengikuti dari belakang motormu. Tekan C atau tombol 📷 Kamera untuk ganti ke kamera samping. Di mabar lokal, layar terbagi dua (atas P1, bawah P2).

⌨️ Kontrol Keyboard

  • Pemain 1: A gas • S gigi • D nitro
  • Pemain 2: ↑ gas • → gigi • Enter nitro
  • Balap sendiri: Spasi gas • Shift gigi • N nitro (atau A/S/D)

📱 Kontrol Sentuh

Tombol GAS / GIGI / NITRO besar di bawah layar. Tahan GAS, ketuk GIGI & NITRO.

👥 MABAR — Main Bareng

Dua pemain balapan di satu layar (split). Pemain 1 pakai A/S/D, Pemain 2 pakai ↑/→/Enter. Di HP, pakai tombol sentuh di bawah layar.

Balapan online lewat server WebSocket. Satu orang buat room, yang lain gabung pakai kode room.
